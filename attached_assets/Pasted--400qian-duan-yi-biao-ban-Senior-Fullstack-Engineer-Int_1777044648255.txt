2. Adapter 優先吃 snapshot

呼叫：

3. 館別映射

請使用既有：
shared/domain/facilities.ts

映射規則：
- schedule venue.name / shortName / aliases
- 對照 facilityLineGroups.ragicDepartmentAliases / fullName / shortName
- 命中後轉成工作台 facilityKey

不要把班表系統的 venue.key 直接當工作台 facilityKey。

4. 班別判斷

優先使用 export schedule.shift.period：
early | mid | late | custom

若 period=custom 或資料異常，再 fallback：
- startAt hour < 12 => early
- 12 <= hour < 16 => mid
- hour >= 16 => late

但 UI 顯示仍用：
早班 / 中班 / 晚班
