/announcements 查詢參數
參數	說明	範例
q	關鍵字（搜尋 title/summary/原文）	?q=學員
type	類型過濾	?type=rule
page	頁碼（預設 1）	?page=2
limit	每頁筆數（最多 50，預設 20）	?limit=50
前端可以用來分類/過濾的欄位
isMustRead: true → 標紅色重要公告
status → rule_matched_pending_review（規則命中）/ ai_pending_review（AI 審）/ pending_review（等待中）
confidence → 建議 ≥ 0.7 才顯示，< 0.5 可以降低權重
candidateType → 分類標籤（rule/notice/campaign/script...）
isFromSupervisor: true → 主管發的，可以置頂
reasoningTags → 顯示「為什麼這則訊息被認為是公告」
這樣前端就能直接拿到全部的候選資料，自己決定要怎麼篩選和顯示。你那邊開始串接後如果有欄位對不上或需要調整格式，再告訴我。
